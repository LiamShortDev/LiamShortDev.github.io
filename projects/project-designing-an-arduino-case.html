Designing an Arduino Case

Introduction

This page showcases the case designed for an Arduino ESP32 using Autodesk Inventor. 
Rather than using special screws for the Arduino, I added stand offs so that the Arduino can be placed into the case without screws and still be secured.
A channel was added on either side to accommodate the pins that come out of the bottom of the ESP32.
A groove in the top of the case that allows for a flange on the lid to make adding/removing the lid easier for the user.

Case

Tools used to design the case

I used the three different categories of tools: 

  1. Create: I used extrusions to create the body of the case, the M4 screw towers and the standoffs for the arduino to rest in. Extrusions were also used to remove details such as making a hole for the USB-C connector, the vent holes and the lid rest.
  2. Modify: The hole tool was used to carve out the channels into the screw towers and then the thread tool was used upon the holes to allow the bolts to screw into the box.
  3. Pattern: I used the mirror tool to allow me to create the screw tower and standoff in one corner, then mirrored in both planes to place in every corner of the case. I then used the rectangular pattern to duplicate a single ventilation hole into 5 evenly spaced, of which was mirrored to match on both sides.
