PCB Purpose

This PCB is designed to act as the driving and control interface for a modular side-illuminated display, inspired by Lixie-style LED displays. The board integrates an Arduino Nano ESP32, which serves as the central controller for the system, allowing individual segments of the display to be addressed and controlled programmatically. Each output channel consists of an LED driven via a transistor switching stage using BSS123 MOSFETs, enabling the microcontroller to safely control higher current loads required for illumination.

The circuit includes multiple identical driver stages, allowing the design to be modular and scalable for displaying different characters or digits. Current-limiting resistors are used to protect the LEDs, while additional resistors ensure proper gate control of the MOSFETs. Decoupling capacitors are included to stabilise the 3.3V and 5V supply rails, ensuring reliable operation of the microcontroller and LEDs.

Mounting holes and connectors are incorporated to allow easy integration into a physical display structure. Overall, the PCB provides a compact, reusable platform for controlling illuminated acrylic display elements in a visually appealing and electronically efficient manner.
