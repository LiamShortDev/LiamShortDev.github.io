Description of Code

This MATLAB function is designed to extract the dominant frequency components from a time-series signal, even when the input data is irregular or noisy. It first sorts the time and signal arrays to ensure they are in the correct order, which is essential for accurate processing. The signal is then smoothed using a moving average filter to reduce noise while preserving key features such as peaks. To improve frequency resolution, the data is linearly interpolated onto a uniform time grid, allowing the Fast Fourier Transform (FFT) to be applied effectively.

The FFT converts the signal from the time domain into the frequency domain, where the relative power of different frequency components can be analysed. The code then identifies local maxima in the power spectrum, applying a threshold to ignore insignificant noise and excluding very low-frequency (DC) components. These peaks are sorted by their relative strength, and up to the three most dominant frequencies are returned. Overall, the function provides a structured method for analysing signals and identifying key periodic behaviours.
