F1 Timing Replay

Introduction

This page showcases a MATLAB script that can access the past 4 F1 seasons races and replay them second by second for any track

Description of Code

This MATLAB App Designer project is a real-time Formula 1 race replay tool that visualises car positions and leaderboard changes using data from the OpenF1 API. The application retrieves session data, including driver information, positional data, and timing events, and caches responses locally to improve performance and reduce API load.

The simulation is time-driven, using a timer to advance the race relative to real-world elapsed time. Car positions and leaderboard updates are handled using an event-based system, where data is processed sequentially as the simulated time progresses. Driver positions are updated at each frame based on the latest available data point.

The user interface allows selection of season and track, and includes controls to start, pause, and resume the replay, as well as adjust playback speed dynamically. A track map is generated from positional data and displayed alongside moving driver markers coloured by team. A live leaderboard updates throughout the session, reflecting position changes over time.

Overall, the project demonstrates API integration, local data caching, event-driven simulation, and real-time visualisation within an interactive GUI.

Programming In MATLAB Reflection

This project demonstrated strong application of synthesis by integrating API data, event driven simulation and a MATLAB GUI into one system. What went well was structuring data into time ordered events, enabling smooth playback and responsive updates. However, performance issues occurred when handling large datasets and initial designs lacked efficient data management. This could be improved by implementing interpolation, better data structures and optimised querying. To improve further, I would plan data flow earlier, test scalability sooner and refine performance through profiling and incremental optimisation, ensuring the system remains efficient and visually smooth under higher loads in future real deployments.
