2D Fluid Simulation GPU

GPU-accelerated real-time fluid simulation using C#, OpenTK and compute shaders.

Overview

A real-time 2D fluid simulation developed in C# using OpenTK and GPU compute shaders. The project explores numerical fluid simulation techniques while using the GPU to perform computationally intensive operations in parallel.

The simulation models the behaviour of an incompressible fluid on a two-dimensional grid, allowing fluid motion and interactions to be visualised in real time.

Key Features

  • Real-time 2D fluid simulation running on the GPU.
  • Custom rendering using OpenTK.
  • GPU compute shaders for computationally intensive simulation steps.
  • Diffusion and pressure calculations performed in parallel.
  • Interactive simulation allowing the user to influence the fluid.
  • Custom numerical methods for solving the fluid equations.

GPU Compute

One of the main goals of the project was to move the expensive calculations away from the CPU and onto the GPU. The simulation uses compute shaders to perform operations across the simulation grid in parallel.

Why GPU acceleration?
Fluid simulation involves repeatedly performing similar calculations across large numbers of grid cells. This makes the problem well suited to the highly parallel architecture of a modern GPU.

Diffusion and pressure-solving operations are implemented using compute shaders, reducing the amount of work that needs to be handled sequentially by the CPU.

Fluid Simulation

The simulation represents the fluid using a two-dimensional grid. Physical quantities such as velocity and pressure are calculated over the grid and repeatedly updated to produce the resulting fluid motion.

A key part of the implementation is the pressure solve. The pressure field is calculated to enforce the incompressibility constraint, producing a velocity field that more closely represents the behaviour of an incompressible fluid.

Technical Challenges

  • Designing a GPU-based architecture where simulation data could be processed efficiently in parallel.
  • Translating numerical algorithms into compute-shader implementations while maintaining stable simulation behaviour.
  • Managing data between the C# application, OpenGL and GPU buffers.
  • Balancing simulation accuracy, stability and real-time performance.
  • Debugging issues across both CPU-side C# code and GPU-side shader code.

  • Performance considerations when designing real-time simulations.
  • Debugging complex interactions between CPU and GPU code.
